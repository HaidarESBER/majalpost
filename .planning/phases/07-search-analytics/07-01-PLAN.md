<task type="auto">
  <name>Task 2: Create search API endpoint</name>
  <files>backend/src/routes/search.ts, backend/src/routes/index.ts, shared/types/api.ts</files>
  <action>
1. Create backend/src/routes/search.ts:
   - Import Router, Request, Response from express
   - Import Article model
   - Import ApiResponse, ApiError from types
   - Create router instance

2. Implement GET /search endpoint:
   - Query parameters: q (search query, required), limit (default: 20), offset (default: 0), category (optional filter)
   - Use Article.find({ $text: { $search: q } }) for text search
   - Add { score: { $meta: "textScore" } } to projection
   - Sort by { score: { $meta: "textScore" } } descending
   - Filter by isPublished: true (only show published articles)
   - If category provided, add category filter
   - Apply limit and skip for pagination
   - Select fields: _id, title, excerpt, slug, featuredImage, category, tags, author, publishedAt, createdAt
   - Return ApiResponse with results array and total count

3. Add pagination metadata:
   - total: total count of matching documents (use countDocuments)
   - limit: requested limit
   - offset: requested offset
   - hasMore: boolean indicating if more results exist

4. Error handling:
   - Validate q parameter (return 400 if missing or empty)
   - Catch MongoDB errors and return 500
   - Use ApiError class for consistent error format

5. Update backend/src/routes/index.ts:
   - Import searchRoutes from './search.js'
   - Mount on '/search' path: router.use('/search', searchRoutes)

6. Update shared/types/api.ts:
   - Add SearchResult interface:
     * _id: string
     * title: string
     * excerpt: string
     * slug: string
     * featuredImage?: string
     * category: { _id: string, name: string, slug: string }
     * tags: Array<{ _id: string, name: string, slug: string }>
     * author: { _id: string, name: string }
     * publishedAt: Date
     * score?: number (text search relevance score)
   - Add SearchResponse interface:
     * results: SearchResult[]
     * pagination: { total: number, limit: number, offset: number, hasMore: boolean }

Use MongoDB native text search. For future enhancements, consider implementing Arabic-specific search improvements.
