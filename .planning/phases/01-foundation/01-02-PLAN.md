<task type="auto">
  <name>Task 1: Initialize Express project with TypeScript</name>
  <files>backend/package.json, backend/tsconfig.json, backend/src/index.ts</files>
  <action>
1. Create `backend/` directory
2. Initialize npm: `cd backend && npm init -y`
3. Install dependencies:
   - Production: express, cors, helmet, mongoose, dotenv
   - Dev: typescript, @types/node, @types/express, @types/cors, ts-node-dev, eslint, @typescript-eslint/parser, @typescript-eslint/eslint-plugin

4. Create tsconfig.json with:
   - target: ES2020
   - module: NodeNext
   - moduleResolution: NodeNext
   - outDir: ./dist
   - rootDir: ./src
   - strict: true
   - esModuleInterop: true

5. Create src/index.ts with basic Express app:
   - Import express, cors, helmet
   - Create app instance
   - Add JSON body parser
   - Add CORS middleware (configure for frontend origin)
   - Add Helmet for security headers
   - Add health check endpoint: GET /api/health returns { status: 'ok', timestamp }
   - Listen on PORT from env (default 5000)

6. Add scripts to package.json:
   - "dev": "ts-node-dev --respawn src/index.ts"
   - "build": "tsc"
   - "start": "node dist/index.js"

Do NOT use CommonJS - use ES modules with NodeNext resolution.
  </action>
  <verify>cd backend && npm run dev starts server, curl http://localhost:5000/api/health returns OK</verify>
